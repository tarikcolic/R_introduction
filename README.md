# R Introduction

This repository contains introductory resources for learning the R programming language. It is designed for beginners who want to build a strong foundation in R syntax, data structures, functions, analysis, and data visualization.

## How to get started

1. **Install the prerequisites:** Install R and RStudio from the official [R Project website](https://www.r-project.org/).
2. **Open the project:** Download or clone this repository, then open `R_introduction.Rproj` in RStudio.
3. **Review the prerequisites:** Make sure you are comfortable with basic programming concepts and using folders and files.
4. **Explore the examples:** Open the scripts in the folders below and run them in RStudio.
5. **Practice:** Modify an example, rerun it, and compare the output with your expectations.

> Tip: Start with the earliest numbered files and work through them in order. The examples are designed to build on one another.

## What you'll learn

- R syntax and program structure
- Variables, vectors, matrices, data frames, and lists
- Conditional statements and loops
- Functions and vectorized operations
- Reading and writing data
- Data visualization and analysis
- Basic statistical concepts and reproducible workflows

## Project structure

The repository is organized by topic so you can move through the material in a clear sequence:

- `1-5 Plots and charts/` — basic plots, bar charts, histograms, scatterplots, and overlaying plots
- `6-8 Functions/` — summaries, descriptive statistics, and case selection
- `9-10 Data formats/` — data formats and factor variables
- `images/` — supporting images used by the examples
- `R_introduction.Rproj` — the RStudio project file
- `README.md` — this guide and repository overview

Run the scripts from the RStudio project window. When a script uses data or images from another folder, keep the repository structure intact.

## Prerequisites

- Basic familiarity with programming concepts
- R and RStudio installed on your computer
- A basic understanding of files and folders
